### 3.3 핵심 알고리즘 (from_meter_factor, BR-05)

```
to_base(value, unit)   = value            if unit == meter
                       = value / factor   otherwise

from_base(base, unit)  = base             if unit == meter
                       = base * factor    otherwise

convert_all(value, from_unit):
  base = to_base(value, from_unit)
  return [ConversionResult(target, from_base(base, target)) for target in all_units()]
```

### 4.4 출력 포맷 (U-OUT-01)

**입력:** `meter:2.5`

**출력 (`TableFormatter.format`):**

```
2.5 meter = 2.5 meter
2.5 meter = 8.2 feet
2.5 meter = 2.7 yard
```

**정규식 패턴 (테스트 SSOT):**

```regex
^\s*2\.5\s+meter\s*=\s*[\d.]+\s+(meter|feet|yard)\s*$
```

### 4.5 처리 흐름 (U-OUT-01)

```
raw_input
  → InputParser.parse_convert_input()
  → ConvertUseCase.execute()        # InputValidator는 U-OUT에서 미호출
  → TableFormatter.format()
  → FormattedOutput.lines
```

U-IN-03은 Parser 성공 후 `InputValidator.validate_convert_request()`가 음수를 거부하는 **SRP 분리**를 검증한다.
