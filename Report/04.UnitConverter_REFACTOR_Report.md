### 4.3 처리 흐름

```
stdin (또는 run_once raw)
  → InputParser.parse_convert_input()
  → InputValidator.validate_convert_request()
  → ConvertUseCase.execute()
  → TableFormatter.format()
  → stdout (FormattedOutput.lines)
```

오류 시 PRD §8 메시지 출력, exit code `1`.

### 4.4 `CliApp` API

| 메서드 | 용도 |
|--------|------|
| `create_default()` | `config/units.json` 기반 기본 앱 |
| `run_once(raw: str)` | 단일 변환 — 테스트·스크립트용 |
| `run(input_fn, output_fn)` | 대화형 1회 — exit code 반환 |
